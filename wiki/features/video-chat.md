# Video chat
## What it does
Anonymous 1-to-1 video with strangers: 18+ and terms gate (signed-in adults skip it, since login already asks), Start, Skip, Stop, Report, Block, interest tags (key words), display name, text chat with the partner, and call recording that starts at once, with signed-in partners told (random chat and rooms).
## How it works
`src/VideoPage.jsx` uses `src/useCall.js` (shared with rooms), which opens one WebSocket on Start, joins with a random device id, and runs WebRTC with the ICE servers the backend sends. Text chat goes over the same socket (`chat`/`chatSent`); messages are rendered as text only and cleared when the call ends. The name is kept in `localStorage` (`vibezoneName`) and sent with `join`. Recording (`src/recorder.js`, used from `useCall`): Record starts recording at once on this device and sends `recordStart`; Stop sends `recordStop`. There is no consent dialog. A signed-in partner gets a notice ("… is recording this call", then "… stopped recording") and a REC badge with the elapsed time; a guest partner is told nothing. Each side's recording is independent and only the recorder can stop it. The recorder captures both videos side by side on a 1280×480 canvas plus both voices mixed with Web Audio, through MediaRecorder (WebM, or MP4 on Safari). Stop, skip, hang-up or a lost connection downloads `vibezone-call-YYYY-MM-DD-HHMM.webm|mp4`; nothing is uploaded. The recorder's badge shows `REC mm:ss`; it shows the partner's recording when I am not recording. Preferences (`src/prefs.js`, `localStorage` key `vibezonePrefs`, gear button in the call controls on both pages, and the `/settings` page in the sidebar, user menu and phone tabs; both render the icon option cards in `src/PreferencesForm.jsx`, native radios styled with CSS; changes apply when you press Save (Cancel in the dialog drops them)): stage layout `focus` (partner full screen, you in a corner) or `split` (partner top and you below on phones, side by side on desktop; a `split` class on `.stage`, only while in a call), and recording output type (video side by side, Instagram Reel — vertical 9:16, partner on top, MP4 preferred — or audio only), quality (low, standard, high: canvas size and bitrate) and format (auto, WebM, MP4; unsupported formats are disabled). Recording settings are read when Record starts. Add friend: when both of you are signed in, the call's Add friend button works during the call, and for 10 minutes after it ends the waiting panel offers `Add <name> as a friend` (`LastPartnerFriend` in `src/CallView.jsx`, random chat and rooms; it sends the same `friendRequest`, which the server applies to the last partner, and goes away on the next match). Android wraps the same build with Capacitor; the iOS app redirects `/chat` to `/rooms` (see rooms.md).
## Tests
`pnpm test:e2e` with frontend and backend running: calls, skip, block, report, chat both ways, partner name, chat cleared on skip, HTML shown as text, onboarding tour, recording (starts at once, a guest partner sees nothing, stop and skip both download a file; in rooms a signed-in partner sees the notice and badge), preferences (split layout geometry on phone and desktop, audio-only WebM recording).
## Limits
No video moderation; the chat word filter is a small list. Device ids can be reset by clearing app data. Guests are not told when they are recorded (the consent screen says calls can be recorded), and anyone can record the screen with other software.
