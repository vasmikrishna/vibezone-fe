# Video chat
## What it does
Anonymous 1-to-1 video with strangers: 18+ and terms gate, Start, Skip, Stop, Report, Block, interest tags (key words), display name, text chat with the partner, and call recording with the partner's consent (random chat and rooms).
## How it works
`src/VideoPage.jsx` uses `src/useCall.js` (shared with rooms), which opens one WebSocket on Start, joins with a random device id, and runs WebRTC with the ICE servers the backend sends. Text chat goes over the same socket (`chat`/`chatSent`); messages are rendered as text only and cleared when the call ends. The name is kept in `localStorage` (`vibezoneName`) and sent with `join`. Recording (`src/recorder.js`, used from `useCall`): Record sends `recordRequest`; the partner sees a consent dialog and answers with `recordAccept` or `recordDecline` (no answer in 30 s withdraws the request). Only the side that asked records: both videos side by side on a 1280×480 canvas plus both voices mixed with Web Audio, through MediaRecorder (WebM, or MP4 on Safari). Stop, the partner stopping, skip, hang-up or a lost connection downloads `vibezone-call-YYYY-MM-DD-HHMM.webm|mp4`; nothing is uploaded. Both sides show a REC badge with the elapsed time. Preferences (`src/prefs.js`, `localStorage` key `vibezonePrefs`, gear button in the call controls on both pages, and the `/settings` page in the sidebar, user menu and phone tabs; both render the icon option cards in `src/PreferencesForm.jsx`, native radios styled with CSS): stage layout `focus` (partner full screen, you in a corner) or `split` (partner top and you below on phones, side by side on desktop; a `split` class on `.stage`), and recording output type (video or audio only), quality (low, standard, high: canvas size and bitrate) and format (auto, WebM, MP4; unsupported formats are disabled). Recording settings are read when Record starts. Android wraps the same build with Capacitor; the iOS app redirects `/chat` to `/rooms` (see rooms.md).
## Tests
`pnpm test:e2e` with frontend and backend running: calls, skip, block, report, chat both ways, partner name, chat cleared on skip, HTML shown as text, onboarding tour, recording (decline then allow, REC on both sides, stop and skip both download a file), preferences (split layout geometry on phone and desktop, audio-only WebM recording).
## Limits
No video moderation; the chat word filter is a small list. Device ids can be reset by clearing app data. A recording is only as honest as the consent dialog: the partner can still record the screen with other software.
